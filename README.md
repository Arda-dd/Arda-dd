**[Stepcast](https://github.com/Arda-dd/stepcast)**: interactive product demos, without the subscription

<a href="https://github.com/Arda-dd/stepcast"><img src="https://raw.githubusercontent.com/Arda-dd/stepcast/main/docs/demo.gif" alt="Stepcast demo"></a>

Record clicks in any web app with a Chrome extension, edit them in the browser (hotspots, zoom, blur), and export a single HTML file people can click through. A free alternative to Arcade, Supademo and Storylane.

`TypeScript` `React` `Chrome Extension (MV3)` `Vite` `Puppeteer`

**[prelaunch](https://github.com/Arda-dd/prelaunch)**: catch launch-day mistakes in one command

<a href="https://github.com/Arda-dd/prelaunch"><img src="https://raw.githubusercontent.com/Arda-dd/prelaunch/main/docs/report.png" alt="prelaunch HTML report"></a>

`npx prelaunch example.com` checks 39 rules before a site goes live: leftover `noindex`, exposed `.env` files, PHP errors shown to visitors, broken links, missing share images, security headers. Also a GitHub Action.

`TypeScript` `Node.js` `CLI` `GitHub Actions`
